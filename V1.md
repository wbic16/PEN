# PEN v1 — hub activation (2026-11-23, EE 210)

Built under Will's order "Build PEN" (2026-11-23 00:27 CST), on the
charter in PEN.md and ARCHITECTURE.md. Hub only (aletheia-core) for v1.

## The three seats, as programs

- **N (worker) — `pen.py census`.** Builds the per-user program registry
  (`registry/<node>.phext`) from what actually runs on the node: user and
  system services, plus every live process executable grouped by owner.
  The registry is the closed input set at substrate scale; it is data,
  and its diff is the review.
- **P (warrior) — `pen.py watch`, every 5 min (pen-watch.timer).**
  Compares live processes owned by the substrate owner against the
  registry. An unexpected program is recorded in `register.phext` with
  full provenance and, once it has lived 45 s (not a transient),
  quarantined: SIGSTOP — frozen for review, reversible, never destroyed.
  The termination leg exists but fires only for executables named in
  `config/pen.json: terminate_exes`, which is **empty by default**: the
  charter names no program class for termination, so v1 terminates
  nothing and quarantines-and-reports everything unexpected.
- **E (religious) — `pen.py audit`, hourly (pen-audit.timer).** Verifies
  the register is complete (every entry carries event/seat/at/ee/node),
  the watcher is not stale, and the watch timer is active; heals by
  running a watch cycle or restarting the timer and recording the heal;
  writes `reports/audit-<date>.md`; commits and pushes the register,
  registry, and reports to this repo.

Every event — census, cycle, drift, quarantine, heal, audit — lands in
`register.phext`, append-only phext, one scroll per event.

## Bounds (v1)

- PEN acts on the owner's own node only; peers are watched, never
  touched (principle 5; ARCHITECTURE.md, termination bounded by
  ownership).
- Quarantine is a freeze, not a kill. Release a frozen program with
  `kill -CONT <pid>` after review, and record the release in the
  register (an `event: release` scroll) — the record is the audit.
- Census granularity is the executable; shared-library watching is v2.
